# George Sewata Motseatsea — Portfolio Website

A personal portfolio website built for the Web Development module (Information Technology:
System Development, Year 2) at Gauteng City College. It showcases my background, skills,
and projects as an IT student focused on Java, databases, and full-stack web development.

**Live site:** _add your GitHub Pages URL here once deployed, e.g._
`https://GeorgeSew.github.io/portfolio/`

## Technologies used

- **HTML5** — semantic page structure (header, nav, main, section, article, footer)
- **CSS3** — custom design system (CSS variables), responsive grid/flexbox layout, no framework
- **JavaScript (vanilla)** — no libraries or frameworks
- **Fonts:** Space Grotesk, IBM Plex Sans, IBM Plex Mono (Google Fonts)

## Features

- Responsive layout for desktop, tablet, and mobile
- Mobile navigation menu with animated toggle
- Typewriter-style animated role text in the hero section
- Filterable project grid (filter by Java / Database / Web)
- Sticky header with smooth-scroll navigation
- Course/education timeline
- Respects `prefers-reduced-motion` for accessibility

## Running locally

1. Clone the repository:
   ```
   git clone https://github.com/GeorgeSew/<your-repo-name>.git
   ```
2. Open the folder and open `index.html` directly in your browser — no build step or server required.

## Deploying to GitHub Pages

1. Push this project to a public GitHub repository.
2. Go to **Settings → Pages** on the repository.
3. Under "Build and deployment", select the `main` branch and `/ (root)` folder, then save.
4. Wait a minute for GitHub to publish, then test the live URL in a private/incognito window.
